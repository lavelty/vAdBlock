# vAdBlock

The ultimate ad and pop-up blocking extension. Fast, lightweight, and completely customizable.

## Features
- **Sponsor Skip**: Automatically skips sponsored segments in YouTube videos using community-sourced data.
- **Advanced Filtering**: Powered by custom vAdBlock lists and uBlockOrigin filters.
- **Privacy Protection**: Blocks tracking scripts and WebRTC leaks.
- **Customizable UI**: Fully themeable with Dark/Light modes and advanced whitelist options.

## Contributing
To report issues with broken websites or missing ads, please visit our filter repository: [vAssets](https://github.com/vAdBlock/vAssets).
For issues relating to the extension itself (bugs, UI issues), use the issue tracker in this repository.
